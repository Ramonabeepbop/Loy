PICTURES YOU CAN SWAP
=====================
Replace a PNG here with yours, keep the same file name, and refresh. Nothing else to change.

images/about/   the photo on each river's About page, named after the fish
                (rice-fields, friends, blossoms, sky-lanterns, whirlpool, lanterns, lotus-pond, dragon-waves, floating-market).
                Square works best (about 1200 x 1200). Transparent PNGs show a soft grey square behind them.

images/shop/    one picture per shop item.
                loy-blue / loy-green / loy-red / loy-yellow   the original Loy keychain
                ripple-<fish>                                 the ripple keychains
                Square (about 1200 x 1200) fits the circle exactly; other shapes get cropped to the middle, so keep the item centred.

To add a new shop item: put its PNG in images/shop/ and copy one line in CONFIG.shop in app.js (name, price, picture path).

images/about-us.png   the picture on the About Loy page (menu > About us). Square works best.
